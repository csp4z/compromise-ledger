# Security policy

## Reporting a vulnerability

Please report security issues **privately** through
[GitHub private vulnerability reporting](https://github.com/csp4z/compromise-ledger/security/advisories/new).
Do not open a public issue.

You can expect an acknowledgement within 5 business days. Please allow up to 90 days for a fix
before public disclosure. Credit is given in the advisory unless you prefer otherwise.

## Scope

In scope: code in this repository, published container images, and the project's public site and
API once they are live.

Out of scope:
- Vulnerabilities in third-party products that appear *in the dataset*. Report those to the vendor.
- Volumetric denial-of-service testing against the public site.

## Not a submission channel

This project does not accept leaked data, credentials, or breach dumps through any channel.
Anything of that kind sent to the project is deleted without being reviewed.

To correct or remove a record in the dataset, see [CORRECTIONS.md](CORRECTIONS.md).
